# Custom Deck Themes

Five custom reveal.js template themes are available under this folder.

## How to switch themes
Edit `poc/deck/index.html` and change the `custom-theme` stylesheet href.

Current line:
```html
<link rel="stylesheet" href="./assets/themes/theme-01-midnight-blueprint.css" id="custom-theme" />
```

Replace with one of:
- `./assets/themes/theme-01-midnight-blueprint.css`
- `./assets/themes/theme-02-paper-signal.css`
- `./assets/themes/theme-03-ember-ledger.css`
- `./assets/themes/theme-04-forest-console.css`
- `./assets/themes/theme-05-graphite-coral.css`

## Color naming convention
Within the theme files and showcase, colors are now described as:
- **Background**
- **Headings**
- **Highlight**
- **Body text**
- **Muted**
- **Success**
- **Warning**
- **Error**

## Theme catalog

Theme 01 is now the visual base. Themes 02–05 keep the same theme-01 palette, semantic colours, and background treatment, and vary primarily by typography.

### 01 — Midnight Blueprint
- **Direction:** Favourite / deck default
- **Heading font:** Merriweather
- **Body font:** Merriweather Sans
- **Background:** theme-01 structural background with archival linework
- **Swatches:**
  - Background `#0a0a0a`
  - Headings `#7b8fa8`
  - Highlight `#bdd6f8`
  - Body text `#f5f4f0`
  - Muted `#f5f4f066`
  - Success `#7eaf88`
  - Warning `#d09257`
  - Error `#c9777a`
